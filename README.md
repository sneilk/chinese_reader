# chinese_reader

Читалка китайских веб-новелл для изучающего язык. Глава загружается по ссылке,
режется на слова, переводится целиком и открывается на телефоне: удержание на
слове даёт подсказку с переводом, двойной тап — карточку с переводом
предложения и статьями из словарей, а поправленные вручную границы слов
запоминаются и применяются к следующим главам.

Проект личный, на одного пользователя. Отсюда и решения: SQLite вместо
сервера баз данных, отсутствие очередей, три экрана вместо кабинета.

## Как это работает

```
POST /api/chapters {url}
   → браузер открывает страницу (headful под Xvfb — иначе сайт отдаёт 403)
   → адаптер сайта достаёт текст главы, отсекая навигацию
   → нормализация в канон: по нему считаются все офсеты
   → резка на предложения → сегментация jieba → status=segmented  ← УЖЕ ЧИТАЕМА
   → перевод батчами ≤10 000 символов → status=ready
```

Пять статусов существуют ради одной границы: где глава перестаёт быть
читаемой. Отказ переводчика её не отменяет — текст и разметка уже в базе,
глава остаётся на `segmented` и читается без перевода.

Ключевая величина всюду — **офсет в каноне**. Токены, предложения, контексты
сохранённых слов ссылаются на один и тот же нормализованный текст, поэтому
разметку можно переделать, не трогая содержимое.

## Из чего собрано

| Слой | Что там |
|---|---|
| `backend/app/fetchers` | загрузка через Playwright с постоянным профилем |
| `backend/app/adapters` | извлечение главы: свой адаптер сайта + generic-фолбэк |
| `backend/app/lang` | нормализация, резка на предложения, сегментация, пиньинь |
| `backend/app/providers` | Яндекс.Переводчик за общим интерфейсом |
| `backend/app/services` | конвейер, словари, личный словарь, бюджет |
| `backend/app/api` | ручки главы, словаря, слов, диагностики |
| `web/src/reader` | рендер по токенам, жесты, панель перевода |

Зависимости выбраны скупо: на фронте только React и Vite, без библиотек
состояния и маршрутизации; на бэкенде FastAPI, SQLAlchemy, jieba, httpx.

## Запуск для разработки

```bash
# бэкенд
cd backend
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/alembic upgrade head
PYTHONPATH=. .venv/bin/python scripts/import_cedict.py   # словарь и userdict
.venv/bin/uvicorn app.main:app --reload

# фронт (в другом окне)
cd web && npm install && npm run dev
```

Открывается на `localhost:5173`, запросы к `/api` проксируются на бэкенд.
Без ключа переводчика всё работает, только главы останавливаются на
`segmented` — это штатный режим, а не поломка.

Проверки: `.venv/bin/python -m pytest` и `.venv/bin/ruff check .` в `backend/`,
`npm run build` и `npm run lint` в `web/`.

## Данные и лицензии

Словарные дампы в репозиторий не кладутся — качаются скриптами при настройке.

- **CC-CEDICT** — китайско-английский словарь, [mdbg.net](https://www.mdbg.net/chinese/dictionary?page=cc-cedict),
  лицензия [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
  Атрибуция обязательна и по условиям лицензии, и по-человечески.
- **БКРС** — большой китайско-русский словарь, [bkrs.info](https://bkrs.info/),
  ежедневная выгрузка в формате DSL.

Тексты глав принадлежат их правообладателям: сервис загружает их для личного
чтения и никуда не публикует.
